### Four independent decisions

1. **Print-to-Cut Registration Checker.** Intent: cut is uniformly offset versus worse at far edge, print-to-cut error measurement, contour cut position drift. [Silhouette troubleshooting](https://silhouetteamerica.freshdesk.com/support/solutions/articles/35000276219-print-and-cut-troubleshooting), [Graphtec support](https://graphtecamerica.com/print-and-cut-issues/) and [Roland guidance](https://support.rolanddg.com/hc/en-us/articles/18580202588185-Print-and-Cut-Misalignment) establish the repeated production problem. [Print Test](https://print-test.com/calibration/print-and-cut-calibration-test/) provides a printable reference, and machine calibration is normally built in. The narrower gap is numerical analysis of already measured vectors: mean shift, directional trends and residuals against the entered limit. Unlike a printer scale check, both references come from the same printed/cut sheet. No diagnosis of the physical cause or calibration values.
2. **Print-and-Cut Laminate Clearance Planner.** Intent: keep sensor marks uncovered when laminating, size and locate one laminate piece on a real printed sheet, detect impossible mark/art coverage. [Cricut media/mark troubleshooting](https://help.cricut.com/hc/en-us/articles/360009426434-Machine-cannot-read-the-cut-sensor-marks) and [operator registration discussion](https://www.reddit.com/r/cricut/comments/161iyvv) support the recurring symptom. [NechEmpire](https://nechempire.com/print-then-cut-planner/) fits stickers in a print/cut area; it does not answer this measured laminate rectangle problem. The existing site's lamination cost tool estimates material/cost, not forbidden-zone geometry. A fit does not guarantee a mark read.
3. **Kiss-Cut Sticker Clearance Checker.** Intent: check mixed-size neighboring sticker cut gaps, compare nominal spacing to measured local movement, locate actual conflicting pairs. [StickerApp's production requirements](https://stickerapp.com/support/stickers/products/sticker-sheet/sticker-sheet-layout-requirements) and [StickerGiant's setup guide](https://support.stickergiant.com/hc/en-us/articles/24764931649172-How-to-Set-Up-Your-Artwork-for-Sticker-Sheets) establish the placement/spacing task. [PixGauge](https://pixgauge.com/sticker-sheet-calculator) offers free uniform fit, rotation and a template; [Sticker Sheet Studio](https://github.com/nsprdjake/sticker-sheet-studio) supports artwork layout. The selected tool instead screens a pre-existing mixed placement with explicit uncertainty. It does not draw/pack artwork, compete with the site's bleed or Imposition counts, or treat shared translation as relative motion.
4. **Vinyl Cutter Test Coupon Generator.** Intent: test cut SVG, compare corner closure and small shapes after material/blade changes, create repeatable custom-size control pieces. [USCutter blade-offset guidance](https://support.uscutter.com/support/solutions/articles/153000143426-blade-offset), [cutter test procedure](https://uscutter.com/content/PDFs/TitanSE_UserManual_Oct30_2017.pdf) and [Atlanta Vinyl's free fixed test SVG](https://atlantavinylstore.com/products/test-cut-svg) establish a tangible task and alternative. The gap is a configurable repeat matrix of equally wide closed shapes with full-sheet physical SVG dimensions, no machine commands. This tests unprinted shape behavior, not printed-to-cut alignment.

Independence: the decisions are **interpret measured displacement**, **find a cover rectangle**, **audit pair clearance**, **produce trial geometry**. None is a direction, unit or presentation variant of another. Known competing utility is retained as counter-evidence. The long-tail opportunity is narrower than “sticker maker,” and does not depend on all four tools owning empty SERPs. Each can be used independently on a job revision, stock/film change, repeated proof, or cutter setup. Browser-only numeric inputs, bounded geometry and no equipment/stock database keep maintenance low. No photos or job data are uploaded. No physical acceptance, manufacturer certification, or guaranteed traffic is claimed.
