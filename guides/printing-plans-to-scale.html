How to Print CAD Plans to Scale

Treat scale as a measured production characteristic: establish the source geometry, calculate the intended output, choose media, plot a check sheet and release only after physical verification.

Purpose and production context

Record the file revision, sheet number, page size, stated drawing ratio and one or more known dimensions. In a CAD layout, model geometry is normally drawn at 1:1 and the viewport or plot setup establishes the sheet scale. In a PDF, the page already has physical boxes and may have been exported, scanned or reduced after authoring.

Do not assume that a title-block label proves the current file is still at that scale. Tender sets, email copies and scan archives are often resized. If the drawing says “Do not scale,” use only stated dimensions or the source model for production decisions.

Definitions and distinctions

A ratio such as 1:50 describes representation: one unit on the sheet equals 50 units in reality. Print percentage describes a transformation of an already laid-out page. Sheet size describes available media. Confusing these three values is the root of many plot-room errors.

Use the Plan Print Scaling Calculator when changing ratios. The print percentage is source denominator ÷ target denominator × 100. A 1:100 source becomes 1:50 at 200%; it does not become 1:50 at 50%.

Inputs, units and method

At a ratio 1:n, printed millimetres equal real millimetres ÷ n. Add title blocks, notes and a clear edge that covers both the design margin and the plotter's non-printable area. Then compare the required rectangle with stocked ISO, ANSI or ARCH sheets in both orientations.

The Plot Sheet Fit Planner performs this geometry check. A result that fits nominal A2 may still clip if the device cannot print to the edge, so use the actual driver specification or a measured printable area.

4. Configure the PDF viewer, driver or RIP deliberately

Select the intended device, paper and orientation before setting scale. Use “Actual size” or the calculated custom percentage, and turn off automatic fitting, shrinking and expansion. Confirm that multiple pages are not being imposed, poster-tiled or rotated by a saved preset.

Preview the page boundary and check that the intended PDF box is being used. An application can print the CropBox while another uses the MediaBox; unexpected white space may trigger a different automatic fit. Save the approved setup as a named preset only after verification.

5. Measure a check plot before releasing the set

Print one sheet containing a long, known horizontal or vertical dimension. Calculate the expected physical length, measure between defined endpoints, and use Printed Scale Verification to identify effective ratio and percentage deviation.

Where dimensional accuracy is important, check both axes. A uniform error may be corrected with a controlled percentage and a new proof. Different horizontal and vertical errors suggest scanning, feed or media distortion; one scale percentage cannot correct both.

Worked production example

A consultant supplies an A3 detail marked 1:100, but the site needs 1:50. The scale conversion is 200%. A source 100 mm check bar should become 200 mm. The operator calculates the enlarged content footprint, selects A1 landscape with the required edge clearance, disables fit-to-page and plots one proof.

The proof check dimension measures 199.6 mm. That is 0.2% undersize relative to the 200 mm target. If the project's release tolerance accepts that deviation, the ticket records the measured value and the set proceeds. If not, the operator investigates the preset and media, applies a controlled correction only after identifying a uniform error, and measures a second proof.

Alternative route: tile a temporary markup set

If a calibrated large-format device is unavailable, calculate the finished plan footprint and use the Plan Tiling Calculator with the small printer's measured printable area. Add a shared overlap, page labels and assembly map.

Tiling is appropriate for temporary markup or review, not automatically for fabrication. Verify a dimension across a seam because independent page fitting or inconsistent trimming can break scale even when each tile looks correct.

Decision checklist

  1. Confirm file revision, sheet number, page box, stated ratio and source units.
  2. Identify one long known dimension; reject scaling from an unverified screenshot or photo.
  3. Calculate any ratio change as an explicit print percentage.
  4. Calculate the plotted footprint and select the actual stocked sheet or roll width.
  5. Set device, media, orientation and output scale; disable automatic fit and shrink options.
  6. Print one proof and measure a known dimension on the physical sheet.
  7. Compare the deviation with the job's defined tolerance and diagnose two-axis differences.
  8. Record file, preset, media, expected length, measured length, disposition and operator.

Common mistakes and cautions

Reversing the source and target denominators produces the wrong percentage. Selecting a smaller paper after entering a custom scale can re-enable fit-to-page. Measuring a short graphic scale with a thick line creates false confidence, while a copied or scanned sheet may carry different distortion in the feed direction.

Other failures include using nominal paper rather than printable area, applying a correction on top of an already corrected PDF, and releasing quantity from an on-screen ruler. Preserve the approved source and alter only the output setting whenever possible.
