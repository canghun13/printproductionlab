Start with an approved source revision

Variable printing connects a customer data record to a physical piece. A readable spreadsheet is not sufficient: a portrait can be missing, a name can overflow or a correctly printed batch can be cut into the wrong sequence. These tools address source structure, asset reconciliation, text geometry and physical collection order separately. Keep an immutable source copy and a stable record ID so every diagnostic result can be traced back to the data owner.

Choose the next check

  1. Use CSV Preflight when importing a new export or diagnosing malformed records.
  2. Use the Image Asset Matcher for each variable-image column and the explicitly selected job package.
  3. Use Variable Text Fit to identify names or fields needing a real-layout proof.
  4. Use the CSV Sequencer only after the cutter's pile collection route is known.

The sequencer exports one complete physical sheet per row, not a finished PDF. Its expanded field sets must be mapped to an approved sheet template before a single-record merge.

What stays local

Pasted text, selected CSV files, asset paths and optional fonts are processed by this browser. The tools do not upload job data, connect to a printer, fetch linked images or save the source into browser storage. Diagnostic downloads are distinct from production exports: a production CSV must retain the exact business text, whereas a report can add formula-safety prefixes. Treat customer data and downloaded files according to your own access and retention policy.

Prove the last lift as well as the first

A successful merge preview cannot prove final cutting order. Make a numbered dummy using the actual across/down arrangement, press delivery orientation, maximum sheets per lift and pile collection route. Include a partial final lift with blank cells, then reconcile every original record once after cutting. Check variable images and the worst text records inside the actual compositor; browser text metrics do not reproduce threaded frames, tables, automatic hyphenation or all font behavior.
