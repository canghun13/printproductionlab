Kiss-Cut Sticker Clearance Checker

Check a placed mixed-size sticker sheet, not a theoretical pieces-per-sheet count. Find which neighboring cut boxes become too close under your declared local error bounds.

Enter measurements or use the example, then run the check.

Detailed result

What this calculator solves

A sticker sheet can fit the requested number of pieces and still leave too little room between two neighboring cuts. This checker uses the actual placed rectangles, including mixed sizes. It finds problem pairs and boxes whose allowed movement would cross a sheet edge, so the layout can be revised before repeating a proof.

How to choose the inputs

Enter the usable sheet region, then the bounding rectangle of each nominal cut contour. Use a single origin and put each item on one row in job order. Start from the cut geometry, not the raster image edge. The X and Y bounds represent the magnitude of independent local displacement per sticker. Use measurements from the applicable stock and machine or a documented job allowance.

How the calculation works

Each nominal rectangle is expanded on both sides by its entered X and Y movement. The minimum distance between two rectangles is the hypotenuse of the non-overlapping horizontal and vertical gaps; touching or overlapping boxes give zero. Applying the same distance formula to expanded rectangles gives a conservative independent-movement gap. The report compares that gap with your required spacing and checks each envelope against the sheet boundary.

Worked production example

The first example box starts at X 10 and ends at X 50 mm. The second starts at X 52 mm with overlapping Y ranges, so its nominal gap is 2 mm. With an independent ±0.6 mm X bound on each sticker, the conservative gap is 2 − 0.6 − 0.6 = 0.8 mm. A 1 mm job requirement flags this pair. Move the second piece by at least 0.2 mm farther from the first and rerun the other pairs before approving the proof.

How to interpret the result

Use the row numbers to find and recheck the tightest placements. A box screen can flag two diagonal or curved shapes whose actual cuts are sufficiently separated. Check the vector outline in the source layout before redesigning. If cut geometry extends over the allowed region, move or resize the placement rather than ignoring the edge warning.

When screening a production revision, use the same row ordering as the source layout. Compare the nearest pair before and after each move. Moving one flagged sticker can reduce another gap, so do not treat the suggested change from a two-item example as a complete layout repair. Rerun the whole sheet and confirm the actual contour at the closest points.

Common production mistakes

A common translation of the whole sheet does not reduce the relative gap between stickers. Do not use that observed shared shift as independent local movement unless you intentionally want a conservative screen. Do not count print bleed twice: if the supplier requires additional zones around a cut, define the screened box and gap on that basis explicitly.

Production assumptions and limitations

The model uses axis-aligned bounding boxes and translation only. It does not parse curves, rotate designs, enforce artwork bleed, optimize nesting, generate a cut path or account for local rotations. Keep marks, bleed and stock restrictions separate. A passing numeric screen does not replace the manufacturer's layout and release requirements.
